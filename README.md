# TRACK24 PROJECT

## 프로젝트 소개
AI를 활용한 결정 지원 Web 서비스입니다.
사용자가 음식, 음악, 영화 등의 선택에 고민이 있을 때 추천 결과를 제공하는 서비스입니다.

## 사용 기술
- Java
- JSP / Servlet
- Oracle DB
- HTML / CSS
- JavaScript

## 주요 기능
- 회원가입 / 로그인
- 마이페이지
- 결과 이력 저장 기능
- 카테고리별 추천 기능

## 담당 역할
- 회원 기능 구현
- 마이페이지 구현
- 결과 이력 기능 개발
- Oracle DB 연동 처리
